Privacy Policy

Last updated September 2026

BreathCheck is built to need as little of your data as possible. Here's exactly what happens, in plain language.

No account, no personal data collection

There's no sign-up, no login, and no form on this site that asks for your name, email, or any personal information. BreathCheck has no backend server and no database — it's a static website.

Where your test results and streak actually live

Your assessment results, exercise history, and streak are stored using your browser's localStorage — a standard web technology that keeps data only on your own device. This information is never transmitted to us or to anyone else. We simply have no way to see it. Clearing your browser's site data, or using a private/incognito window, removes it completely.

Lightweight local usage logging

To understand how the assessment and exercises are used, BreathCheck logs a small number of basic events (like "test started" or "exercise completed") — but these are also written only to your browser's local storage, not sent to any server. At this stage, nobody but you can see this log. If that ever changes — for example, if we connect a proper analytics service to understand usage across visitors — this policy will be updated to say so clearly.

Fonts

This site loads typefaces from Google Fonts. As a normal part of how web fonts work, this means your browser makes a request to Google's servers when the page loads, which exposes your IP address to Google the same way it would for any site using their font service. We don't control or see this data ourselves.

Hosting

BreathCheck is hosted on GitHub Pages. GitHub may log standard web server access information (like IP addresses) as part of operating their hosting service — this is governed by GitHub's own privacy statement, not by us.

Cookies

BreathCheck doesn't set cookies of its own.

Questions

If anything here is unclear, reach out via the contact page.
